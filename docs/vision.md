# Техническое видение

Документ — отправная точка для разработки Telegram LLM-ассистента из `docs/idea.md`. Цель: максимально простое решение для проверки идеи.

## Технологии

| Слой | Выбор |
|---|---|
| Язык | Python 3.12 |
| Зависимости | uv (`pyproject.toml` + lock-файл) |
| Telegram | aiogram 3, long polling |
| LLM | пакет openai, API OpenRouter |
| Конфиг | переменные окружения |
| Логи | стандартный модуль `logging` |
| Запуск | Make (локально и через Docker) |
| Контейнер | Docker и docker-compose только для локального запуска |

Других библиотек нет: ни БД, ни Redis, ни веб-фреймворка, ни webhook.

Стек выбран так, чтобы бот можно было запустить у себя на компьютере, без публичного сервера и без лишних сервисов.
