# my_first_bot

Telegram-бот, который ведёт диалог с пользователем и отвечает на вопросы с помощью LLM (через OpenRouter). Роль и стиль ответов задаются системным промптом.

Стек: Python 3.12, `uv`, aiogram 3 (long polling), пакет `openai` + OpenRouter, Make, Docker (только локально). Подробнее: [`docs/vision.md`](docs/vision.md).

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен. Ключ OpenRouter берётся на [openrouter.ai/keys](https://openrouter.ai/keys).
2. Скопируйте `.env.example` в `.env` и заполните значения:

   | Переменная | Обязательна | Описание |
   |---|---|---|
   | `TELEGRAM_TOKEN` | да | токен бота от BotFather |
   | `OPENROUTER_API_KEY` | да | ключ OpenRouter |
   | `MODEL_NAME` | нет | модель, по умолчанию `openai/gpt-4o-mini` |
   | `LOG_LEVEL` | нет | уровень логов, по умолчанию `INFO` |

   Файл `.env` не попадает в git и в Docker-образ. Не публикуйте токен и ключ.

3. Запустите одним из способов (нужны [uv](https://docs.astral.sh/uv/) и Make; для Docker ещё Docker Desktop):

   ```
   # локально
   make install
   make run

   # в Docker
   make docker-build
   make docker-run
   ```

   Одновременно запускайте только один экземпляр бота: два процесса с одним токеном конфликтуют.

Остановка: `Ctrl+C`. Другие цели Make: `venv`, `clean`.

## Как пользоваться

- `/start` — приветствие.
- Любой текст — ответ модели. Бот помнит последние 20 сообщений чата.
- Стикеры, фото и другие нетекстовые сообщения — бот просит написать текстом.
- Сообщение длиннее 2000 символов — вежливый отказ.
- При сбое модели (таймаут, лимиты, недоступность, ошибка ключа) пользователь получает короткое понятное сообщение, бот продолжает работать.

## Настройка

- Роль и стиль бота: константа `SYSTEM_PROMPT` в `src/my_first_bot/config.py`.
- Размер истории (`MAX_HISTORY`) и лимит ввода (`MAX_INPUT_CHARS`): `src/my_first_bot/telegram_bot.py`.
- Лимит длины ответа (`MAX_TOKENS`): `src/my_first_bot/llm_client.py`.

## Что готово к показу

MVP реализован по плану [`docs/tasklist.md`](docs/tasklist.md):

- запуск локально и в Docker, ответ на `/start`;
- LLM-ответы через OpenRouter;
- контекст диалога в рамках чата;
- системный промпт с единым стилем поведения;
- обработка ошибок, пустых и слишком длинных сообщений.

## Ограничения MVP

- История диалогов хранится только в памяти и пропадает при перезапуске.
- Нет базы данных, webhook и хостинга: бот работает, пока запущен на вашем компьютере.
- Нет автотестов и CI.
