# ADR 0001. Стек MVP для Telegram LLM-ассистента

- Статус: принято
- Дата: 2026-09-17
- Связано: `docs/idea.md`, `docs/vision.md`

## Контекст

Нужно проверить идею из `docs/idea.md`: диалог в Telegram, ответы языковой модели с ролью из системного промпта.

Цель первой версии — запустить бота на своём компьютере, без публичного сервера и без лишних сервисов. Рассматривались альтернативы по слоям: язык, библиотека Telegram, polling или webhook, LLM-провайдер, менеджер зависимостей, хостинг и сборка без кода.

## Решение

Берём простой стек из `docs/vision.md` и не меняем его до рабочей проверки идеи.

| Слой | Выбор |
|---|---|
| Язык | Python 3.12 |
| Зависимости | uv, `pyproject.toml`, lock-файл |
| Telegram | aiogram 3, long polling |
| LLM | пакет openai, API OpenRouter |
| Конфиг | переменные окружения |
| Логи | стандартный модуль `logging` |
| Запуск | Make (локально и через Docker) |
| Контейнер | Docker и docker-compose только для локального запуска |

В MVP нет базы данных, Redis, веб-фреймворка и webhook.

OpenRouter используем как единую кассу к разным моделям: один ключ и один формат запроса, смена модели без переписывания бота. Сам OpenRouter текст не генерирует.

## Альтернативы

- python-telegram-bot вместо aiogram 3 — тот же Bot API, другой стиль кода. Не даёт преимущества для этой идеи.
- Node.js / TypeScript (grammY, Telegraf) или Go — имеют смысл, если команда уже на этом языке. Для LLM-чата Python короче.
- Telethon / Pyrogram — клиент пользовательского аккаунта, не Bot API. Для ассистента в BotFather не нужны.
- Webhook, VPS, Railway, Fly.io — когда бот должен работать круглосуточно. Для локальной проверки лишние.
- Прямой API OpenAI / Anthropic / Gemini или LiteLLM — возможны позже; OpenRouter проще сменить модель.
- Ollama — если важнее приватность, чем простота и качество в облаке.
- n8n / Make — прототип без репозитория, слабый контроль над кодом.
- ManyChat, Botpress, Mini App, serverless — другой продукт или неудобны для длинных ответов LLM.

pip, poetry, pdm вместо uv не улучшают бота, только меняют установку пакетов.

## Последствия

- Бот можно запустить локально: программа сама забирает сообщения из Telegram, сайт и домен не нужны.
- История диалога между перезапусками не хранится, пока нет базы.
- Секреты (токен бота, ключ OpenRouter) живут в окружении, не в коде.
- Счёт за ответы модели идёт через OpenRouter.
- Переход на webhook и хостинг — отдельное решение после того, как диалог с системным промптом уже работает.
